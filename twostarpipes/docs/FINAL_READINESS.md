## Necessary local corrections

- Notification settings stay disabled until a successful initial load, preventing accidental overwrite after a failed load. Old settings/job state clears when the session changes. Failed loading no longer claims that no jobs exist.
- Product creation/import waits for successful loading. Product switching, form edits and cancellation are disabled during uploads/saves so an upload cannot attach to a different selected product. A PDF cannot be selected as an image or vice versa. Server authorization, MIME/signature and size checks remain in place.
- Private admin/API/server-function responses now carry `X-Robots-Tag: noindex, nofollow, noarchive`, in addition to existing no-store/framing protections.
- The light-only header remains centered, with language on the right beside the mobile menu. Smaller controls avoid overlap at 320px; tests measure positions rather than merely checking page overflow.
- Split read-only preflight check 12 inventories existing public functions and public/Storage triggers, owners, SECURITY DEFINER flags, search paths and ACLs without selecting bodies or arbitrary function configuration values.
- Successful browser screenshots are optional (`QA_SCREENSHOTS=1`). Failure screenshots remain enabled in Playwright. Assertions are unchanged.
